# telli for Claude

Connect Claude to telli through Charlie. Build and improve AI voice agents, create workflows, and review calls directly from Claude.

Sign in with your telli account through OAuth.

Install in Claude Code:

```sh
claude plugin marketplace add telli-ai/claude-plugin
claude plugin install telli@telli-plugins
```

Restart Claude Code. Run `/mcp`, select telli, and sign in with your telli account.
